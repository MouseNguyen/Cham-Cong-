## Main result

The source plan is a strong starting brief but must not yet be treated as a final implementation contract. The earlier short-contract PIT contradiction is resolved for MVP because every supported full-time and part-time worker uses the supplied 12-month contract from day one, with the six-day probation embedded at the same salary/rate. Full-time workers use an employee-specific gross monthly salary currently around VND 7-8 million; part-time workers use an employee-specific gross hourly rate currently VND 26,000. Employee-side insurance and PIT are deducted and itemized to derive net pay; net-salary gross-up is excluded. Compensation terms are effective-dated and validated against the applicable workplace minimum. Exact excess time is retained and flagged; the accountant drafts its classification and the owner makes the final approval before payroll. The home Windows host is confirmed available 24/7. Local inspection found Cloudflare WARP running and `cloudflared.exe` installed, but no active/configured tunnel was proven; the approved temporary route is to start a Cloudflare Tunnel only after the isolated attendance endpoint passes locally, with a named tunnel and owner-controlled domain deferred to production.
