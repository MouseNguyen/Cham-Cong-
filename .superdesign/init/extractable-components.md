# Extractable components

## Layout components

None. The current app has only the minimal RootLayout and no reusable application shell, navigation, sidebar, header, footer, or breadcrumb.

## Basic components

None. Buttons, fields, cards, badges, tables, status notices, and dialogs are currently page-local markup.

## Extraction decision

Skip Superdesign component extraction for W5-01. PAY-W5-02 will create the approved shared primitives from the selected design system; extracting the current page-local markup would preserve temporary structure rather than a reusable product contract.
